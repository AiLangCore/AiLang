# AiLang Archive

Status: historical context.

This directory contains superseded plans, release notes, migration notes, and
historical documents retained for context.

Archive documents are not normative and must not be used as current tasking
unless explicitly revived into `../Planning/`, `../Design/`, `../Docs/`, or
`../SPEC/`.

Archived files should use either:

- an `*.archive.md` suffix, or
- a dated subdirectory such as `2026-beta/`.
